Train your own adapter: pick a run to start from, make a new run from it, change the model or what it learns, then Run everything. A run is a recipe (tune/recipes/*.json); each stage runs tune/pipeline.py and skips what is already done, so a paused run resumes where it was. Training takes the GPU (on the 4090: about an hour to cache the calls through the model, an hour or so of training, two hours of tests) and the stages start their own model server, so the app's is stopped first; Load models brings it back.

Add a base model: another model to call on and train on, from Hugging Face
        
Two repos on huggingface.co: the quantized GGUF the app runs, and the full-precision checkpoint the trainer learns on (the same model). It has to be a family the trainer knows (Gemma 4, Ministral 3, Qwen3.6, gpt-oss); a new family needs code (README, Training your own adapter). Check looks it up without changing anything; Add puts it in models/bases.json; Download fetches both, with what training needs, and resumes if stopped.
